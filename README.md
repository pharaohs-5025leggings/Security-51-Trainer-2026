## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Security 51**. This trainer adds convenience options for Security 51, helping players manage survival pressure while exploring the facility and completing security duties. The available options focus on player survivability, movement, interaction, and resource management without changing the game's core investigation and horror experience.

**Target Audience:** Players who want a more relaxed way to explore Security 51, review its facility and surveillance sequences, reduce chase pressure, or replay the horror experience without repeated failures.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Use the movement option after entering the facility and gaining control of the character. A moderate speed increase is recommended for navigating corridors and returning to security stations. Keep the option disabled during scripted sequences if movement becomes too fast or causes positioning problems.

### Tools & Inventory

Security 51 centers on investigation and the use of security equipment rather than a large conventional inventory. Use the resource option only when battery-powered tools are active. Interaction assistance can help with doors, terminals, cameras, and other required objects, but it should be disabled when switching objectives or loading a new area.

### World & Environment

Explore the facility carefully and use surveillance systems to monitor activity and identify changes in the environment. The trainer can reduce resource pressure and make backtracking easier, but objectives, clues, scripted events, and progression triggers still need to be completed normally.

### Combat & Weapons

Security 51 is primarily a horror and investigation experience rather than a conventional combat game. When hostile encounters or pursuit sequences occur, use the survivability and threat-control options to avoid being overwhelmed. These options are intended for escape and exploration, not for adding weapons or a combat system that is not part of the game.
